# 📚 BIBLIOTEC

O **BIBLIOTEC** é um projeto de site desenvolvido para apresentar uma livraria virtual, permitindo que os usuários explorem livros, conheçam diferentes gêneros literários e visualizem informações sobre obras disponíveis.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, com foco em uma interface simples, organizada e intuitiva.

## 🖥️ Tecnologias utilizadas

- **HTML5:** estruturação das páginas.
- **CSS3:** estilização e organização visual do site.
- **JavaScript:** implementação de interações e funcionalidades.
- **LocalStorage:** armazenamento local de informações no navegador (quando utilizado).

## ✨ Funcionalidades

### Página inicial
- Apresentação da livraria.
- Exibição de livros em destaque.
- Navegação entre as páginas.

### Catálogo
- Apresentação de diferentes gêneros literários.
- Pesquisa de gêneros por nome ou descrição.
- Categorias como:
  - Fantasia;
  - Romance;
  - Suspense;
  - Terror;
  - Ficção científica;
  - Aventura;
  - Drama;
  - Biografia;
  - História.

### Página do livro
- Exibição de informações sobre a obra.
- Apresentação da sinopse.
- Exibição de avaliações e comentários.
- Formulário para envio de avaliações.

### Carrinho
- Exibição dos livros selecionados.
- Remoção individual de livros.
- Limpeza completa do carrinho.
- Cálculo automático do valor total.

### Cadastro
- Formulário para inserir nome e e-mail.
- Campo para criação de senha.
- Confirmação de senha.
- Validação dos campos obrigatórios.

## 🎨 Identidade visual

O BIBLIOTEC utiliza uma identidade visual baseada em tons de azul e amarelo, buscando transmitir organização e facilitar a navegação.

As páginas compartilham elementos visuais, como cabeçalho e rodapé, mantendo a consistência da interface.

## 🚀 Como executar o projeto

1. Baixe ou extraia os arquivos do projeto.
2. Abra a pasta `BIBLIOTEC` no Visual Studio Code.
3. Verifique se as pastas `assets`, `css` e `js` estão organizadas corretamente.
4. Abra o arquivo `index.html` no navegador.

Também é possível utilizar a extensão **Live Server** do Visual Studio Code para executar o projeto em um servidor local.

## ⚠️ Observações

- O cadastro atual realiza validações no navegador, mas não possui integração com banco de dados.
- O carrinho presente na versão enviada utiliza livros definidos diretamente no HTML.
- Os links de exploração dos gêneros ainda dependem da criação da página `livros.html`.
- Os caminhos dos arquivos CSS, JavaScript e imagens devem corresponder à estrutura real das pastas.
